# IT415 POS Practical Exam Requirements

## Required Transaction Flow

1. Item Selection
2. Order Summary
3. Payment Method
4. Payment Processing
5. Payment Successful
6. Receipt
7. New Transaction

## Required Functionality

- At least six selectable products
- Large touchscreen-oriented controls
- Display product names and prices
- Increase/decrease quantity
- Remove products
- Calculate item subtotals
- Calculate total
- Order Summary
- Back navigation preserves order
- Cash payment
- Reject insufficient cash
- Calculate change
- Simulated QR payment
- Simulated Credit/Debit Card payment
- Payment Successful screen
- Unique transaction reference
- Digital receipt
- New Transaction resets transaction state
- Meaningful feedback

## Technical Choices

- Frontend: React + TypeScript + Vite
- Backend: FastAPI
- Storage: Static/in-memory
- Payments: Simulated
- Database: None
